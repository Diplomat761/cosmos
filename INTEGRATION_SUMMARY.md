## 📋 Структура базы данных

Используется существующая БД `jsk_kosmos.sql` с таблицами:

1. **users** - Пользователи (жильцы)
2. **meter_readings** - Показания счетчиков
3. **requests** - Заявки
4. **news** - Новости
5. **tariffs** - Тарифы
6. **documents** - Документы

## 🔧 Настройка

### Шаг 1: Импорт БД
```bash
mysql -u root -p jsk_kosmos < jsk_kosmos.sql
```

### Шаг 2: Настройка подключения
Отредактируйте `php/config.php`:
```php
define('DB_HOST', '127.0.0.1');
define('DB_NAME', 'jsk_kosmos');
define('DB_USER', 'root');
define('DB_PASS', 'ваш_пароль');
```

### Шаг 3: Создание директорий
```bash
mkdir -p uploads/requests
chmod 755 uploads/requests
```

### Шаг 4: Добавление тестовых данных (опционально)
Откройте в браузере: `http://localhost/php/init_test_data.php`

## 🚀 Использование

### Передача показаний
1. Пользователь заполняет форму на `meters.html`
2. Данные отправляются на `php/submit_meters.php`
3. Скрипт проверяет пользователя и сохраняет показания в БД
4. Возвращается ответ с ID записи

### Подача заявки
1. Пользователь заполняет форму на `requests.html`
2. Данные отправляются на `php/submit_request.php`
3. Генерируется номер заявки
4. Фото сохраняется в `uploads/requests/`
5. Заявка сохраняется в БД

### Отображение новостей
1. При загрузке `index.html` автоматически вызывается `loadNews()`
2. Запрос отправляется на `php/api/news.php`
3. Новости отображаются на странице

## 🐛 Устранение неполадок

### Новости не загружаются
- Проверьте консоль браузера (F12)
- Убедитесь, что в таблице `news` есть данные
- Проверьте доступность `php/api/news.php`

### Показания/заявки не сохраняются
- Проверьте логи PHP
- Убедитесь, что пользователь существует в БД
- Проверьте, что статус пользователя = 'active'

### Ошибка подключения к БД
- Проверьте настройки в `php/config.php`
- Убедитесь, что MySQL/MariaDB запущен
- Проверьте права доступа пользователя БД
