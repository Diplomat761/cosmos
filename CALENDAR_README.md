# Python Календари

В этом проекте созданы три различных календаря на Python:

## 📅 1. Консольный календарь (`my_calendar.py`)

Простой календарь для работы в командной строке.

### Использование:
```bash
python my_calendar.py
```

### Возможности:
- Отображение текущего месяца
- Отображение любого месяца и года
- Отображение всего года
- Информация о текущей дате
- Проверка високосного года

### Примеры кода:
```python
import my_calendar

print(my_calendar.show_month(2024, 1))  # Календарь на январь 2024
print(my_calendar.show_year(2024))      # Календарь на весь 2024 год
print(my_calendar.is_leap_year(2024))   # True
```

## 🖥️ 2. Графический календарь (`calendar_gui.py`)

Календарь с графическим интерфейсом на Tkinter.

### Использование:
```bash
python calendar_gui.py
```

### Возможности:
- Визуальный календарь с кнопками
- Навигация по месяцам и годам
- Выделение текущего дня
- Информация о выбранном месяце
- Клик по дням для получения информации

### Требования:
```bash
pip install tk
```

## 🌐 3. Веб-календарь (`web_calendar.py`)

Веб-приложение календаря на Flask.

### Использование:
```bash
python web_calendar.py
```

Затем откройте в браузере: http://localhost:5000

### Возможности:
- Современный веб-интерфейс
- Просмотр месяца или года
- Адаптивный дизайн
- REST API для получения данных календаря
- Красивый CSS дизайн

### Требования:
```bash
pip install flask
```

## 🚀 Быстрый запуск

### Для веб-календаря:
```bash
pip install flask
python web_calendar.py
```

### Для GUI календаря:
```bash
python calendar_gui.py
```

### Для консольного календаря:
```bash
python my_calendar.py
```

## 📋 API Веб-календаря

### Получить календарь месяца:
```
GET /api/calendar/{year}/{month}
```

### Получить календарь года:
```
GET /api/year/{year}
```

## 🎨 Кастомизация

Все календари легко модифицировать:
- Изменить языки (добавьте свои названия месяцев)
- Добавить праздники или события
- Изменить цветовую схему
- Добавить дополнительные функции

## 📝 Примечания

- Календари используют встроенный модуль `calendar` Python
- Поддерживают все стандартные функции календаря
- Локализованы на русский язык
- Совместимы с Python 3.6+
